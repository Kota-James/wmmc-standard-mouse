# NucleoMouse2023 — WMMC マイクロマウス標準プログラム

STM32 Nucleo-32（STM32F303K8）を使ったクラシックマウス用の標準プログラム。
配布後、パラメータ調整のみで探索走行・二次走行ができる。

> 現在、教育用教材への改修を進行中。分析・方針は [docs/](docs/README.md) を参照。

## ハードウェア構成

| 項目 | 内容 |
|---|---|
| MCU | STM32F303K8（Nucleo-32, Cortex-M4F 64MHz, Flash 64KB / RAM 12KB） |
| モータ | ステッピングモータ ×2（モータドライバ SLA707x 系, CW/CCW + Clock 方式） |
| センサ | 赤外線壁センサ ×4（左・右・前左・前右）+ バッテリ電圧監視 |
| UI | タクトスイッチ ×3（SW1: +, SW2: -, SW3: 決定）、LED ×4 |
| 通信 | UART2 115200bps（ST-Link の Virtual COM Port 経由で printf 出力） |

ピン割り当ては `Core/Inc/main.h` のユーザーラベル定義を参照。

## 開発環境・ビルド

1. STM32CubeIDE をインストールし、このリポジトリを import（Existing Projects into Workspace）
2. ビルドして ST-Link 経由で書き込み

HAL ドライバ本体（`Drivers/`）はリポジトリに含まれているため、クローン直後にそのまま
ビルドできる。ピン設定や周辺機能を変更するときだけ `NucleoMouse2023.ioc` を
CubeMX（CubeIDE 内蔵）で開いてコード生成し直す（CubeMX 6.17 / FW_F3 V1.11.6 で管理）。

## モード一覧（SW1/SW2 で選択、SW3 で決定）

| Mode | 内容 |
|---|---|
| 0 | 壁制御の基準値取得（通常は走行前に自動実行される） |
| 1 | 探索走行（足立法）。ゴール到達後に帰り探索し、マップを EEPROM に保存 |
| 2 | 二次走行（保存済みマップで走行）。※Mode 1 を完走してから実行すること。ファームを書き換えた直後もマップ保存前の扱いになるため Mode 1 からやり直す |
| 3-5 | 空き（オートスタート等の自作モード用） |
| 6 | テスト走行（直進・旋回のパラメータ調整用サブメニュー） |
| 7 | センサチェック（AD 値を UART に出力。壁判定閾値の調整用） |

## パラメータ調整

調整対象は `Core/Inc/params.h` に集約されている。
手順の詳細は [docs/05_開発運用Tips.md](docs/05_開発運用Tips.md) §4 を参照。
概略: Mode 7 で壁閾値 → Mode 6 で直進距離・旋回角 → 尻当て量 → 壁制御ゲイン → Mode 1/2。
