# テスト迷路

ここで扱う迷路はすべて **16×16区画 = クラシックマウス競技の規格**（この機体が出る競技）。
紛らわしいが、公式大会で「マイクロマウス競技」と呼ばれるのはハーフサイズ
（32×32区画、1区画90mm）の方で、16×16（1区画180mm）は「クラシックマウス競技」が正式名称。
ハーフに挑戦する場合は機体もコード（`MAZE_SIZE` ほか）も別物になる。

## 同梱している迷路

| ファイル | 内容 |
|---|---|
| `empty.maze` | 外周以外に壁がない迷路。アルゴリズムの最初の動作確認用。左手法では**解けない**（なぜかは課題3で） |
| `perfect.maze` | ループのない「完全迷路」。隅をゴールに指定すれば左手法でも必ず解ける（課題3用。実大会の迷路にループの無いものは存在しないため、これだけ自作している） |

## 練習用の本命: 実大会の迷路

過去の全日本大会などの迷路データが GitHub の
[micromouseonline/mazefiles](https://github.com/micromouseonline/mazefiles)
（`classic/` 配下、本シミュレータと同じテキスト形式）に多数まとまっている。
**日本の大会の迷路（`japan〜`）を使えば、ルール準拠（中央2×2ゴールの部屋・
スタート北開き）の「本物」がそのまま手に入る。**

同リポジトリにはライセンス表記がないため、このリポジトリには同梱せず、
各自が次のコマンドで手元に取得する（`real/` は git 管理外）:

```sh
cd Sim/mazes
sh fetch_real.sh          # 全日本2015〜2019などを real/ に取得
cd ..
./sim mazes/real/japan2019.maze
make test                 # real/ に取得済みの迷路も自動でテスト対象になる
```

他の年の迷路が欲しければ mazefiles の `classic/` を眺めて
`fetch_real.sh` の FILES に追記すればよい。

## ゴールの扱い

ゴールの既定値は日本ルールどおり**中央2×2領域（南西角(7,7)）**で、
領域内のどの区画に入っても到達扱いになる。座標を引数で明示した場合は1区画ゴール:

```sh
../sim mazes/real/japan2019.maze     # 中央2×2領域ゴール（大会と同じ）
../sim mazes/perfect.maze 15 15      # (15,15)の1区画をゴールに
```
