# テスト迷路

ここにある迷路はすべて **16×16区画 = クラシックマウス競技の規格**（この機体が出る競技）。
紛らわしいが、公式大会で「マイクロマウス競技」と呼ばれるのはハーフサイズ
（32×32区画、1区画90mm）の方で、16×16（1区画180mm）は「クラシックマウス競技」が正式名称。
ハーフに挑戦する場合は機体もコード（`MAZE_SIZE` ほか）も別物になる。

| ファイル | 内容 |
|---|---|
| `empty.maze` | 外周以外に壁がない迷路。アルゴリズムの最初の動作確認用。左手法では**解けない**（なぜかは課題3で） |
| `practice01.maze` `practice02.maze` | 日本ルール準拠の練習迷路。ループ（回り道）があり、中央の2×2ゴール領域は内壁なしの部屋（入口1箇所） |
| `practice03.maze` | ループのない「完全迷路」。隅をゴールに指定すれば左手法でも必ず解ける（課題3用） |

ゴールの既定値も日本ルールどおり**中央2×2領域（南西角(7,7)）**で、
領域内のどの区画に入っても到達扱いになる。座標を引数で明示した場合は1区画ゴール:

```sh
../sim mazes/practice01.maze          # 中央2×2領域ゴール（大会と同じ）
../sim mazes/practice03.maze 15 15    # (15,15)の1区画をゴールに
```

## 実大会の迷路で試す

過去の全日本大会などの迷路データが GitHub の
[micromouseonline/mazefiles](https://github.com/micromouseonline/mazefiles)
（`classic/` 配下、本シミュレータと同じテキスト形式）に多数まとまっている。

同リポジトリにはライセンス表記がないため、このリポジトリには同梱していない。
使いたい人は次のコマンドで各自の手元に取得する（`real/` は git 管理外）:

```sh
cd Sim/mazes
sh fetch_real.sh
../sim real/japan2019.maze
```

動作確認済み: `japan2019.txt`（全日本2019）で探索〜二次走行まで成功する。
