# 課題3: 左手法 — マップなしで迷路を歩く

実装するファイル: `Core/Src/app/lefthand.c` の `lefthand_run()` 内の判断部分

ここまでの課題1（壁が見える）と課題2（まっすぐ走れる）だけで、
もう迷路を歩けるようになる。地図も計算もいらない最古の迷路攻略法、**左手法**だ。

## ルール

「左手を壁につけたまま歩き続ける」。プログラムにすると、各区画で:

1. **左が空いていれば左折**
2. だめなら**直進**
3. だめなら**右折**
4. 全部だめ（行き止まり）なら **Uターン**

の優先順位で向きを決めて 1 区画進む、を繰り返すだけ。

## 手順

1. まずシミュレータで感覚を掴む:
   ```sh
   cd Sim && make
   ./sim --lefthand mazes/practice03.maze   # → ゴールに着く
   ./sim --lefthand mazes/empty.maze        # → 永遠に着かない！
   ```
2. `lefthand.c` の TODO を実装する
   - 使うもの: `wall_info` と `WALL_LEFT/FRONT/RIGHT`（課題1の成果物）、
     `motion_rotate_*()`、`motion_one_section()`（1区画進んで止まる）
   - **旋回したら `maze_turn()` を忘れずに**。内部の方角情報がずれると
     ゴール判定（現在座標の追跡）が狂う
3. 実機の Mode 3 で走らせる。まずは数区画の小さい迷路で

## 合格条件

- シミュレータの practice03 相当の迷路（ループなし）で実機がゴールに到達する
- **empty.maze で左手法が失敗する理由を自分の言葉で説明できる**

## 考察（重要: これが次の課題への入り口）

- 左手法が**必ず**成功する迷路の条件は何か？
  （ヒント: practice03 は壁が全部「外周とつながって」いる。empty.maze は？）
- 大会の迷路はゴールが中央にあり、周囲にループが仕込まれている。
  つまり左手法では勝てない。**壁を記録し（課題4）、経路を計算する（課題5）**
  必要があるのはこのためだ。
