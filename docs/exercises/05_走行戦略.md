# 課題5: 走行戦略 — 探索走行を完成させる

実装するファイル: `Core/Src/app/strategy.c` の `search_to_goal()` と `strategy_run()`

ここまでの部品（motion / wall / maze / solver）を組み合わせて、
実機で迷路を探索する一連の流れを作る。**実機必須。**

## search_to_goal() — 探索走行の心臓部

基本の流れ:

```
（二次走行なら保存済みマップを読み込む）
スタート区画の壁を見て記録（前壁は無い前提で消す）
最初の半区画を前進
歩数マップと経路を作る
繰り返し:
    route[r_cnt] の動作を実行（前進 / 減速→旋回→加速）
    内部位置を前進させる
    壁を記録し、経路上に壁が見つかったら経路を作り直す（solver_update_route）
ゴールに着いたら半区画減速して停止
2秒以上停止（競技規定）→ 180度回転
（一次走行ならマップを EEPROM に保存）
```

考えるポイント:

- **なぜ半区画単位なのか**: 壁は区画の境目で読むのが一番確実
  （センサが隣の区画の壁を読んでしまわない位置）。だから動作は
  「半区画で加速 → 1区画等速 ×n → 半区画で減速」という構成になる
- **旋回の前後**: 旋回は停止してから（`motion_half_section_decel()` →
  `motion_rotate_*()` → `motion_half_section_accel()`）
- **内部位置と実機位置の同期**: 旋回したら `maze_turn()`、進んだら
  `maze_advance_position()` を必ず呼ぶ。忘れると地図と現実がずれて壁に突っ込む

## strategy_run() — 一連のシナリオ

尻当てで位置合わせ → `get_base()` → ゴールまで探索 → 帰り探索 →
（一次なら）マップ保存 → 励磁を切る、の流れを組む。
尻当ての向き（右→左の 2 回）で縦横両方の位置が揃う理由を考えること。

## 手順

1. まずシミュレータの `Sim/sim_main.c` の `run_search()` を読む
   （同じ流れが「移動が一瞬で終わる」形で書いてある。動く参考書として使う）
2. `search_to_goal()` を実装し、シミュレータの動作と頭の中で対応づける
3. 実機で Mode 1 を実行。小さい迷路（4×4 に仕切る）から始めるとよい
4. Mode 1 完走後、Mode 2（二次走行）を実行

## 合格条件

- 実機で Mode 1（探索・帰り探索）→ Mode 2（二次走行）が完走する

## 発展

- Mode 3 に**オートスタートモード**を作れ: 1回のスイッチ操作で
  「探索 → 数秒待って → 二次走行 ×2」を連続実行する（5分5走を最大活用するため）
- Uターン時に前と横の壁で尻当てし直すと探索の位置誤差がリセットできる
  （`turn_around_with_touch_up` として実装済み/課題。効果を実機で比較せよ）
