# 課題1: 壁判定 — センサ値から壁の有無を判断する

実装するファイル: `Core/Src/app/wall.c` の `get_wall_info()`

## 背景

マウスの壁センサは「赤外線 LED を光らせ、壁からの反射光をフォトトランジスタで
受ける」仕組みになっている。壁が近いほど反射光が強く、AD 値（0〜4095）が大きくなる。
platform 層が 12ms ごとに全センサを自動で読んでくれており、
`hw_sensor_left()` などでいつでも最新値を取れる（`Core/Inc/hw/hw_sensor.h` 参照）。

やることは単純で、**AD 値がしきい値より大きければ「壁あり」** と判断して
`wall_info` にビットを立てるだけ。ただし、しきい値の決め方が本質的に重要になる。

## wall_info のデータ形式

```
0x88 = 前壁   0x44 = 右壁   0x22 = 後壁(センサでは見えない)   0x11 = 左壁
```

「なぜ 1 つの壁に 2 ビットも使うのか？」は課題 4 まで進むと分かる
（ヒント: `wall.h` と `solver.h` の先頭コメント）。

## 手順

1. `wall.c` の `get_wall_info()` の TODO を実装する
   - 前壁は前左・前右の 2 つのセンサがある。**どちらか一方でも**しきい値を
     超えたら前壁ありとするのが定石（斜めから見たとき片方しか反応しないことがある）
2. 実機の Mode 7（センサチェック）で動作確認する
   - 壁を近づけたり離したりして AD 値の変化を観察する
3. しきい値（`Core/Inc/app/params.h` の `WALL_BASE_*`）を調整する
   - 「壁あり時の最小値」と「壁なし時の最大値」を記録し、その中間に設定する

## 合格条件

- Mode 7 で、左・前・右の壁の有無が [X] 表示と一致する
- 区画の中央だけでなく、少し位置をずらしても誤判定しない
