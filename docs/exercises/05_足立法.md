# 課題5: 足立法 — 迷路の解き方

実装するファイル: `Core/Src/app/solver.c` の `solver_make_step_map()` と
`solver_make_route()`

**この課題は実機不要。** シミュレータで開発・確認する。**本教材の山場。**

## 背景: 足立法（歩数マップ法）

1. ゴールの区画に「0」と書く
2. 0 の区画から**壁を挟まずに**行ける隣の区画に「1」と書く
3. 1 の区画から行ける未記入の区画に「2」と書く… を繰り返す
4. 自分のいる区画に数字が書かれたら終了。
   あとは**数字が減る方向に進めば**必ずゴールに着く

紙と鉛筆で 4×4 の迷路を書いて一度手で解いてみること。10 分で本質が分かる。

## solver_make_step_map() の実装

- `smap[y][x]` に歩数を書き込む。未記入は `0xff`
- 壁情報は `maze_wall_bits(x, y)` で取る（一次/二次走行のニブル選択を勝手にやってくれる）
- 上の手順をそのまま素直に書くと「マップ全域を走査して歩数 n の区画を探し、
  隣に n+1 を書く」ループになる。まずはそれでよい（遅いが確実に動く）

## solver_make_route() の実装

- 現在地から歩数が減る方向へたどり、`route[]` に動作列を書く
- `route[]` の形式: 0x88=前進, 0x44=右折, 0x22=Uターン, 0x11=左折
- 「絶対方位で北に進みたい」を「今の向きから見て右折」に変換する必要がある
  （`mouse.dir` との差分。`maze_turn()` で内部方角を回しながら組み立てる）
- 注意: 組み立て中に `mouse.dir` を動かすので、最初に退避して最後に戻すこと

## 手順

1. 歩数マップだけ先に作り、シミュレータの表示（実行の最後に出る）で目視確認する
2. 経路導出を実装し、`./sim mazes/empty.maze`（壁なし）→ 実大会迷路（`sh mazes/fetch_real.sh` で取得 → `./sim mazes/real/japan2019.maze`）の順に試す
3. `make test` が全迷路 PASS になったら合格

## 合格条件

- `Sim/` の `make test` が全迷路 PASS
- 空迷路（empty.maze）での二次走行が 14 歩（理論最短）になる

## 発展（余裕があれば・上級生向け）

- 全域走査方式は歩数×256 回の走査が走る。**キュー（リングバッファ）を使った
  幅優先探索**に書き換え、`clock()` で速度差を計測せよ（数十倍速くなるはず）
- 現在の探索は「最短歩数」だが、実機はターンで減速する。
  「ターン回数が少ない経路」を優先するにはどうすればよいか？
