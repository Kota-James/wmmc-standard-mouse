# 課題3: マップ記録 — 見た壁を地図にする

実装するファイル: `Core/Src/app/maze.c` の `maze_write_walls()`
（`maze_advance_position()` / `maze_turn()` も空欄の場合はあわせて実装する）

**この課題は実機不要。** `Sim/` のシミュレータで開発・確認する。

## 背景

課題1で得た `wall_info` は「機体から見て前・右・左」の壁情報でしかない。
迷路を解くには、これを**絶対方位（北東南西）に直して地図 `map[y][x]` に記録**する
必要がある。

## map のデータ形式（maze.h の先頭コメントも読むこと）

- 各バイトの bit3=北壁, bit2=東壁, bit1=南壁, bit0=西壁
- 下位 4bit: 一次走行用（未探索の壁は「なし」＝楽観的）
- 上位 4bit: 二次走行用（未探索の壁は「あり」＝悲観的）
- 探索で確認できた壁は両方のニブルに書く

## 考えるポイント

1. **向きの補正**: 機体が東（dir=1）を向いているとき、機体の「前壁」は迷路の「東壁」。
   `wall_info` を `mouse.dir` 分シフトすると絶対方位になる（ビット割り当てが
   これを見越して設計されている。紙に書いて確かめよ）
2. **隣の区画との整合性**: 自分の区画の「北壁」は、北隣の区画の「南壁」でもある。
   片方だけ更新すると地図が矛盾する
3. **境界条件**: 最北の区画で北隣に書き込もうとすると配列の外に出る

## 手順

1. `Sim/` で `make` してシミュレータをビルドする
2. `maze_write_walls()` を実装する
3. `./sim mazes/practice01.maze` を実行する。
   マップ記録が間違っていると、経路探索（課題4が実装済みの場合）が壁に突っ込み
   `CRASH` と表示される
4. `make test` で全迷路 PASS になるまで直す

※ 課題4が未実装の場合は route が作れないので、この課題の確認は
「CRASH せず走れているか（暴走メッセージが出ないか）」で見る。

## 合格条件

- シミュレータで CRASH が出ない
- （課題4実装後）`make test` が全迷路 PASS
