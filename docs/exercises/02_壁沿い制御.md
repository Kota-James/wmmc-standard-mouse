# 課題2: 壁沿い制御 — まっすぐ走らせる

実装するファイル: `Core/Src/app/control.c` の `app_control_tick()`

## 背景

ステッピングモータは指示したパルス数だけ正確に回るが、機体の組み立て誤差や
タイヤの滑りで、走っているうちに機体は必ず左右にずれていく。
そこで**壁との距離を一定に保つフィードバック制御**を入れる。

- 基準値 `base_l` / `base_r`: 区画中央にいるときのセンサ値（課題1の `get_base()` が取得）
- 偏差 `dif_l` / `dif_r`: 現在のセンサ値と基準値の差。**正なら壁に近づきすぎ**
- 操作量: `hw_motor_set_steering(left, right)` に渡す値。
  パルス間隔[µs]から引かれるので、**正の値を渡した側の車輪が速くなる**

この関数は割り込みから 12ms ごとに呼ばれる。**printf や長いループは書けない**。

## 手順

1. まず「比例制御（P 制御）」を実装する
   - 偏差に係数（ゲイン `CTRL_CONT`）を掛けた量だけ、壁と反対側へ曲げる
   - 左壁に近づいた → 左車輪を遅く・右車輪を速く（機体は右へ曲がる）
2. 注意点（params.h の定数を使う）
   - **不感帯**: 偏差が `CTRL_BASE_*` 以下なら操作しない（中央付近でフラフラしない）
   - **上限**: 操作量は ±`CTRL_MAX` に制限する（1つのセンサの誤反応で暴れない）
   - 制御が無効（`enabled == 0`）のときは操作量 0 を設定すること
3. 実機の Mode 6 → テスト走行 case 7（6区画直進）で調整する
   - 蛇行する → ゲインを下げる／壁に寄っていく → 不感帯を下げる

## 合格条件

- 両側に壁のある直線 6 区画を、壁に触れずに走り切れる
- わざと少し斜めに置いてスタートしても、中央に復帰する
