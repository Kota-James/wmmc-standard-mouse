## 競技・迷路

| 用語 | 意味 |
|---|---|
| マイクロマウス | 自律ロボットが迷路の最短走行タイムを競う競技。1977年から続く世界最古級のロボコン |
| クラシック / ハーフ | 迷路の規格。クラシックは16×16区画（1区画180mm）、ハーフはその半分サイズで32×32 |
| 区画 | 迷路のマス目1つ。壁は区画の境界に立つ |
| スタート区画 | 迷路の隅（本プログラムでは座標(0,0)）。北方向だけが開いている |
| ゴール | クラシックでは中央の2×2区画。本プログラムは代表点(7,7)を目指す |
| 探索走行（一次走行） | 迷路を知らない状態で壁を記録しながらゴールを目指す走行 |
| 二次走行（最短走行） | 探索で得たマップを使って最短経路を走る走行 |
| 5分5走 | 持ち時間5分以内に最大5回走行できるという競技規則 |
| オートスタート | 1回の操作で探索→最短走行を連続実行させる運用テクニック |
| 足立法 | 歩数マップを使う探索法。考案者の名前に由来する日本発の定番アルゴリズム |
| 歩数マップ | ゴールから各区画までの歩数を書き込んだ表。数字が減る方へ進めばゴールに着く |
| 左手法（壁伝い） | 左の壁に沿って歩き続ける最も単純な迷路攻略法。ループのある迷路では失敗する |
| 尻当て | 機体の後端を壁に押し当てて位置と角度の誤差をリセットする動作 |
| 脱調 | ステッピングモータが指令に追従できず「ガガガ」と滑って位置がずれる現象。加速しすぎ・電圧低下が主因 |

## ハードウェア

| 用語 | 意味 |
|---|---|
| ステッピングモータ | パルスを送った数だけ一定角度ずつ回るモータ。回した量が分かるのでエンコーダ無しで距離が測れる |
| 励磁 | ステッピングモータのコイルに電流を流して保持力を出すこと。励磁中は電池を消費する |
| モータドライバ | マイコンの弱い信号でモータの大電流を制御するIC（本機はSLA707x系） |
| CW / CCW | 時計回り / 反時計回り。モータの回転方向指定 |
| フォトトランジスタ | 光の強さを電流に変える素子。壁センサの受光部 |
| ADC / AD値 | アナログ電圧をデジタル値に変換する仕組み / その結果（本機は0〜4095の12bit） |
| 分圧 | 抵抗2本で電圧を一定比率に下げること。バッテリ電圧(11.1V)をマイコンが読める範囲にしている |
| LiPo（リポ） | リチウムポリマー電池。高出力だが過放電・過充電で発火リスク。専用の充電器と保管袋を使う |
| ST-Link | STM32への書き込み・デバッグを行う装置。Nucleoボードに内蔵されている |
| UART / シリアル通信 | 2本の線でバイト列をやりとりする通信。printfの出力先（115200bpsはその速度） |
| SWD | デバッガがマイコン内部を覗くための2線式インターフェース |

## マイコン・ソフトウェア

| 用語 | 意味 |
|---|---|
| HAL | STが提供するペリフェラル操作ライブラリ（Hardware Abstraction Layer）。`HAL_GPIO_WritePin` など |
| CubeMX / CubeIDE | ピン設定からコードを自動生成するツール / それを含む統合開発環境 |
| ペリフェラル | マイコン内蔵の周辺機能（タイマ・ADC・UARTなど）の総称 |
| タイマ | 一定周期でカウントアップするペリフェラル。PWM出力や周期割り込みに使う |
| PWM | パルスの幅・周期で出力を制御する方式。本機ではモータへのクロック生成に使用 |
| ARR / CCR | タイマの周期を決めるレジスタ / パルスの切り替わり位置を決めるレジスタ |
| 割り込み（ISR） | イベント発生時に実行中の処理を中断して呼ばれる関数。短時間で抜けるのが鉄則。printf禁止 |
| volatile | 「割り込みなどで裏から値が変わりうる」とコンパイラに伝えるC言語の修飾子。最適化による読み飛ばしを防ぐ |
| ビジーウェイト | ループで回り続けて時間を潰す待ち方。単純だがCPUを占有する |
| ニブル | 4bit（1バイトの半分）のこと。本プログラムのマップは上位/下位ニブルを使い分けている |
| ビット演算 | AND(&)/OR(\|)/シフト(<<)などでビット単位の操作をすること。壁情報の処理で多用する |
| Flash / EEPROM | 電源を切っても消えないメモリ。本機はFlashの一部をEEPROM代わりに使いマップを保存する |
| リンカスクリプト | プログラムをメモリのどこに配置するかの指示書（`.ld`ファイル） |
| newlib | 組込み向けの標準Cライブラリ実装。printfの中身はこれ |
| ビルド / 書き込み | ソースを機械語に変換すること / それをマイコンのFlashに転送すること |

## このプロジェクト固有

| 用語 | 意味 |
|---|---|
| app層 | `Core/Src/app/`。アルゴリズム担当。HALを使わないので PC でも動く。新入生の作業場所 |
| platform層 | `Core/Src/platform/`。ハードウェア担当。マイコンを変えるときはここだけ書き直す |
| 境界API | `Core/Inc/hw/*.h`。app層がハードを使うための窓口となる関数群 |
| 加減速テーブル | 1パルスごとのパルス間隔を並べた表（`motor_table.inc`）。テーブルをたどることで滑らかに加減速する |
| wall_info | 自機から見た壁情報（0x88=前, 0x44=右, 0x11=左）。詳細は `app/wall.h` |
| route | 進行順の動作列（前進/右折/Uターン/左折）。詳細は `app/solver.h` |
| シミュレータ | `Sim/`。maze.c/solver.c をPCで動かして迷路アルゴリズムを試す道具 |
| reference ブランチ | 模範解答。まず自力で書き、行き詰まったときの見比べ用 |
